# The Databricks Cost Field Guide

BigHammer.ai's free lead magnet: 13 read-only Databricks system table queries, a scorer and a printable Evidence Sheet.

Live at:
- https://adisuja.github.io/bighammer-cost-field-guide/ (GitHub Pages, served from `main`, root folder)
- https://webinar.bighammerai.com/cost-field-guide/ (branded copy, kept in the `bighammer-masterclass` repo under `cost-field-guide/`)

The site is plain static files. `index.html`, `assets/` and `brand/` are all it needs. `tools/` holds the scripts used to render the share image and check the page; they are not part of the site.
